# Manual QA Portfolio: E-Commerce Web App Testing

This portfolio demonstrates practical manual software testing skills using a public e-commerce demo application such as SauceDemo or OpenCart Demo.

## Project Goal

Show that I can analyze requirements, design test coverage, execute manual tests, report defects clearly, validate APIs, and understand database checks used in real QA work.

## What This Portfolio Includes

- Test plan for an e-commerce web application
- Manual test cases for login, product browsing, cart, checkout, and account flows
- Sample bug reports written in a professional format
- API testing checklist for Postman
- SQL practice queries for backend data validation
- Remote QA job search strategy

## Tools

- Browser: Chrome or Edge
- Bug tracking style: Jira-style reports
- Test management style: TestRail-style test cases
- API testing: Postman
- Database validation: SQL
- Documentation: Markdown, GitHub

## Skills Demonstrated

- Requirement analysis
- Test case design
- Exploratory testing
- Functional testing
- Regression testing
- Boundary and negative testing
- Bug reporting
- API test thinking
- SQL data validation
- Remote QA readiness
