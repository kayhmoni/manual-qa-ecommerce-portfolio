# Remote QA Job Search Strategy

## Target Job Titles

Search for more than "manual tester". Use these titles:

- Manual QA Engineer
- QA Analyst
- Software QA Tester
- Quality Assurance Analyst
- Web QA Tester
- Mobile QA Tester
- API QA Tester
- Test Analyst
- Junior QA Engineer
- QA Engineer

## Weekly Routine

Monday:

- Search company career pages and remote job boards.
- Save 10-15 relevant jobs.

Tuesday:

- Customize resume headline and summary for 5 jobs.
- Apply to roles posted within the last 7 days.

Wednesday:

- Message recruiters or hiring managers on LinkedIn.
- Add portfolio link to each application.

Thursday:

- Practice one QA interview topic.
- Add one improvement to portfolio.

Friday:

- Follow up on previous applications.
- Track responses in a spreadsheet.

## Application Tracker Columns

- Company
- Job title
- Job URL
- Remote region
- Date applied
- Resume version used
- Portfolio included
- Status
- Follow-up date
- Notes
